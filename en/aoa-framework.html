🗺️ Process mapping

  • What tasks do you handle every day? (complete list)
  • How much time do you spend on each task?
  • Which tasks are repetitive and predictable?
  • Which tasks require human judgment?
  • What tools do you currently use?
  • Where are the bottlenecks?
  • What errors occur frequently?

📝 Session notes

💡Quick Win identified: Automate appointment reminders via SMS/email (estimated gain: 3h/week)

🔄 Optimized workflow

  • Remove identified redundant steps
  • Standardize templates (emails, invoices, replies)
  • Group similar tasks (batching)
  • Define automatic triggers (when X → then Y)
  • Document the target workflow (before/after)
  • Validate with the client that the workflow makes sense

🗑️ Removed steps

  • Manual appointment entry → Calendly auto
  • Manual review replies → Template + AI
  • Manual unpaid follow-up → Make.com workflow

📝 Session notes

💡Quick Win identified: Automatic post-appointment email template (estimated gain: 2h/week)

🤖 Claude skills to create

  • Skill "Google review reply" (professional, personalized tone)
  • Skill "Post-appointment email" (summary + next appointment)
  • Skill "Client follow-up" (D+3, D+7, D+14)
  • Skill "Social media post" (3x/week auto)
  • Skill "Invoicing" (generation + sending)

⚙️ Make.com workflows

  • Trigger: New appointment → Confirmation email + D-1 reminder
  • Trigger: Google review → AI reply + Notification
  • Trigger: Unpaid invoice D+7 → Automatic follow-up
  • Schedule: Monday 8am → Week posts scheduled

🚀 Deployment

  • Test each workflow in sandbox mode
  • Client validation before activation
  • Progressive activation (1 workflow/week)
  • First week monitoring
